# NetTag

Program to edit ID3v2 metadata tags on audio files.

![Screenshot.png](FileTagger/Assets/Screenshot.png)

### Installation
- Head to the [Releases](https://github.com/Genteel01/file-tagger-linux/releases/latest) page
- Choose a version
  - rpm package is available for Fedora/RedHat based distros
  - tarball is available for other Linux distros
  - zip containing portable executable is available for Windows
- Install the executable
  - RPM
    - Install using your package manager
    - Run the executable
  - Tarball/zip
    - Extract the executable to your desired location
    - (optional, tarball only) Extract the icon and .desktop files to the correct location
- Run the executable
  
#### NetTag is primarily developed for personal use, on a Fedora Linux system. Other platforms are less tested, but should be fully functional.
